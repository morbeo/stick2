# stick2 docs

The full reference behind the [landing page](../README.md). The app has its own interactive docs too (ⓘ in the top bar, or `docs.html`), with live demo fights and every setting.

| Page | What's in it |
|---|---|
| [Modes](modes.md) | play, grid, impact, character, animate, gallery, tests: what each view does |
| [Fighting](fighting.md) | the engine: guard, combos, throws, specials, projectiles, weapons, power, falls, 2D / 2.5D, stances |
| [Editing](editing.md) | characters, the move table, movement layers, the input table, combos |
| [Interface](interface.md) | in-app docs, ⌘K palette, keys and macros, panels, pause / scrub / undo, sound, factory reset |
| [Development](development.md) | layout, build info, screenshots, the icon font |
| [Testing](testing.md) | `npm test`, snapshots, replays, the browser smoke test, seeds and fuzzing |

Screenshots in [img/](img/) are generated by `node tools/screenshots.js` (headless Chrome); rerun it after a visible change.
